# Coffee R Us Admin Portal

## Overview
Coffee R Us Admin Portal is a React single-page application built for administrators to manage coffee products for an e-commerce website. The app allows users to view products, search through the catalog, add new products, and update product details such as price, description, and origin.

## Features
- Landing page for store/admin portal introduction
- Product catalog page
- Dynamic search functionality
- Add new product form
- Edit existing product details
- Client-side routing with React Router
- Shared state management using Context API
- Custom hook for product fetching
- Responsive layout
- Simulated backend using json-server

## Technologies Used
- React
- React Router DOM
- Context API
- Vite
- JSON Server
- Vitest
- React Testing Library
